RLHF PPO Playground

A from-scratch RLHF pipeline: a BERT reward model trained on Anthropic’s hh-rlhf preferences, plus a distilgpt2 policy fine-tuned with PPO (GAE, KL-penalized rewards, clipped objectives).

  1. uv run python train.py reward — train the reward model
  2. uv run python train.py rollout — sanity-check generation
  3. uv run python train.py ppo — run PPO training

Served locally via python3 -m http.server 8123.
